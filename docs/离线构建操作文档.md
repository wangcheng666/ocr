# OCR 服务离线构建操作文档

本文档描述从「有网机器」准备离线产物，到「离线机器」构建镜像的完整流程。
**全部为命令行命令，不依赖任何脚本。**

> ⚠️ **uv 版本必须对齐**：lockfile 格式与 uv 版本绑定。本项目 Docker 内使用 `uv:0.7.13`，
> 因此下面的 `uv` 命令也要用 0.7.13。若宿主 uv 不是 0.7.13，从 Docker 镜像提取：
> ```bash
> docker create --name uv-tmp ghcr.io/astral-sh/uv:0.7.13
> docker cp uv-tmp:/uv /tmp/uv && docker rm uv-tmp && chmod +x /tmp/uv
> export UV=/tmp/uv          # 之后用 $UV 代替 uv
> ```

---

## 一、离线依赖准备（uv lock 过程，联网机器上执行一次）

生成**通用 lockfile**（同一份锁覆盖 amd64 + arm64），并把两平台 wheel 下载到 `packages/`。

```bash
cd /root/projects/ocr

# 1. 生成通用 lockfile（联网，覆盖两个平台）
uv lock

# 2. 导出依赖列表（排除 workspace member）
uv export --no-dev --format requirements-txt | grep -v '^-e ' > /tmp/ocr-reqs.txt

# 3. 下载 amd64 + arm64 两平台 wheel 到 packages/
python3.13 -m pip download --only-binary=:all: --no-deps \
    --platform manylinux_2_17_x86_64 --platform manylinux2014_x86_64 \
    --platform manylinux_2_17_aarch64 --platform manylinux2014_aarch64 \
    --python-version 3.13 \
    --index-url https://pypi.org/simple \
    -d packages/ -r /tmp/ocr-reqs.txt

# 4. 离线重锁：把 lock 指向本地 packages/（registry="packages"），仍覆盖两平台
uv lock --offline
```

> 说明：第 4 步**不能省略**。纯 `uv sync --offline --find-links packages/` 会失败（锁里仍指向
> PyPI URL）。必须让锁指向本地 `packages/`（`pyproject.toml` 里的 `[[tool.uv.index]]` flat 源 +
> `uv lock --offline`），`uv sync --locked --offline` 才能离线安装。

**产物入库：** 提交 `uv.lock` 与 `packages/`，离线机器 clone 后即可离线构建。

> 也可用 `scripts/download_packages.py` 代替第 2、3 步（内网镜像优先、PyPI 回退、自动跳过已存在）。

## 二、离线构建镜像（离线机器上执行）

```bash
cd /root/projects/ocr

# 当前架构
./build-docker.sh v1.0.0

# 指定架构 / 多平台
./build-docker.sh v1.0.0 amd64
./build-docker.sh v1.0.0 arm64
./build-docker.sh v1.0.0 amd64,arm64
```

主 Dockerfile 使用**预烤基础镜像** `python:3.13-slim-ocr`（amd64）与
`python:3.13-slim-ocr-arm64`（arm64），已含系统依赖 + 字体，无任何 apt/联网步骤，
`uv sync` 全部 `--offline`，构建完全离线。

## 三、文件说明

| 文件 | 用途 |
|---|---|
| `Dockerfile` | 主镜像构建（引用预烤镜像，完全离线） |
| `build-docker.sh` | 镜像构建入口（单/多平台 + manifest 合并） |
| `pyproject.toml` | 依赖声明 + 本地 `packages/` flat index |
| `uv.lock` + `packages/` | 离线产物（通用锁 + 两平台 wheel），入库 |
